# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem, in this SDK or in the LigueLead API.

Report it privately through GitHub instead: open the **Security** tab of this repository and choose
**Report a vulnerability**. Only the maintainers can see the report, and you will get an answer there.

Include what you found, how to reproduce it, and the version of the SDK (`LigueLeadClient.VERSION`).
Never include a real `api-token` in a report: revoke any token you may have exposed.

## Supported versions

Fixes are released on the latest minor version of the current major. Upgrade to it before reporting.
